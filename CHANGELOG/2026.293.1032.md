# 2026.293.1032 — feat(skills): move the quickshell skill body beside its candy, where the loader reads it

## Summary

Moves the `quickshell` skill body out of `candy/plugin-quickshell/charly.yml` and into
`candy/plugin-quickshell/.agents/skills/quickshell/SKILL.md` — beside the candy that declares the node, which is the
directory the loader reads — leaving the `skill:` node carrying only its routing metadata.

| | before | after |
|---|---|---|
| inline `content:` blocks | 1 | 0 |
| skill nodes | 1 | 1 |
| SKILL.md, beside the candy | 0 | 1 |

Diff against `main`: **181 insertions and 164 deletions across two files**.

### Why beside the candy

`sdk/deploykit/skills_collect.go` resolves the tree as `filepath.Join(layer.GetSourceDir(), ".agents/skills")`, and
`GetSourceDir()` is the directory of the candy whose manifest declares the node — here `candy/plugin-quickshell/`. The
node is declared in `candy/plugin-quickshell/charly.yml`, so a body placed at the repository root would be invisible to
the loader while the manifest deletion shipped.
